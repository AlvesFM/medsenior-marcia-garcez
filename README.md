# Márcia Garcez | Planos MedSênior

Landing page da consultora Márcia Garcez de Castro para os planos de saúde MedSênior.

## Arquivos

- `index.html`: a página inteira (HTML, CSS e JavaScript no mesmo arquivo).
- `assets/`: logos e fotos usadas pela página.

## Como alterar

No começo do JavaScript, dentro de `index.html`, fica o bloco `CONFIG`. Ali você troca:

- `whatsapp`: número do WhatsApp (só dígitos, com 55 e DDD).
- `instagram`: link do Instagram.
- `fotoHero`: foto do topo.
- `registroConcessionaria`: número de registro do selo, quando houver.
- `web3formsKey`: chave do Web3Forms para receber o formulário por e-mail. Sem a chave, o formulário envia os dados pelo WhatsApp.

## Publicar

Para publicar de graça no GitHub Pages: Settings › Pages › Branch `main` › pasta `/ (root)` › Save.
